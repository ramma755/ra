# Architectural floor plan drawing

This folder contains a clean CAD redraw of the supplied hand sketch.

- `floor_plan_autocad.dxf` - AutoCAD-compatible DXF drawing.
- `floor_plan_preview.svg` - browser-viewable preview of the same geometry.

The DXF uses millimetres and preserves the main features visible in the sketch:

- overall 4800 x 4600 site boundary
- central residential rooms, passages, kitchen, laundry, kitchen store, and washrooms
- RM 1, RM 2, RM 3, and RM 4
- main entrance, gate, security house, parking structure, and open court
- door swing arcs, windows, basic sanitary/kitchen fixtures, hatching, and dimension lines

Because the source photo is a hand sketch rather than a measured survey, internal room
locations are proportionally traced from the visible layout and labelled dimensions.
