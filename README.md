# Shanice Jones Portfolio

This repository contains a static portfolio website built from the uploaded
resume details.

## Portfolio

Open the site locally:

```bash
cd portfolio
python3 -m http.server 8000
```

Then visit `http://127.0.0.1:8000`.

## Extra templates

The portfolio now includes six additional templates in `portfolio/templates/`:

- 3 gaming portfolios
- 3 software engineering portfolios

Open `portfolio/templates/index.html` to browse them.

## Free hosting

The portfolio can be hosted for free with GitHub Pages, Netlify, Cloudflare
Pages, or Vercel. See `portfolio/README.md` for setup steps.
